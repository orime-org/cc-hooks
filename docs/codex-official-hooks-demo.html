官方 Codex 任务列表流程提案

在项目当前目录执行 codex 或 codex resume。面板先等待，首次原生事件到达后按当前会话的 session_id 加载任务，随后跟随计划变化。

自上而下的数据流

你在 WezTerm 启动官方 Codex
↓
WezTerm 自动事件识别当前 Codex 进程，创建等待状态的底部面板
↓
首次原生事件提供 session_id 与 transcript_path，插件关联对应进程并读取当前会话任务
↓
官方 PostToolUse 匹配 update_plan，插件读取 tool_input.plan 并保存完整任务
↓
底部面板刷新，最多四条；更多任务有数量提示并可滚动

本轮实测：在项目目录按顺序启动的两个会话显示各自任务。原生 Tasks 计数与任务面板读取同一份 update_plan 清单。详细状态见会话事件演示。
