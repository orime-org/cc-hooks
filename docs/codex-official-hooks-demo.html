官方 Codex 任务列表流程提案

日常执行 codex 或 codex resume。终端启动检测负责显示面板，官方工具 hook 负责同步计划。此页用于确认流程。

自上而下的数据流

你在 WezTerm 启动官方 Codex
↓
WezTerm 自动事件识别该 pane 的交互 Codex，创建底部空态面板
↓
官方 SessionStart 或 UserPromptSubmit 提供会话编号，插件关联终端和会话
↓
官方 PostToolUse 匹配 update_plan，插件读取 tool_input.plan 并保存完整任务
↓
底部面板刷新，最多四条；更多任务有数量提示并可滚动

本轮实测：官方 SessionStart 在首条消息时触发。为达到启动即显示，前置空态由 WezTerm 的自动事件创建。共享后台下，终端身份由 WezTerm 提供。

状态演示

实际界面沿用已确认的中文紧凑面板。会话归属无法确定时，由当前 Agent 询问当前用户；确认后保存关联并刷新。
