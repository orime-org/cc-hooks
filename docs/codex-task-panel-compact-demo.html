这个版本的行为

情况你看到的结果
空计划三行：标题、等待状态、操作提示。

高度模式

事件结果
启动或重新打开会话进入自动模式，按目标计划确定高度。
任务条数变化自动模式调整高度；人工模式保持当前尺寸。任务显示上限均为四条。
手动拖动或终端尺寸变化当前连接进入人工模式，保留实际尺寸。
自动调整暂时失败保留当前窗格及计划，提示高度调整失败并重试。
读取缓存失败显示中文缓存错误；恢复有效缓存后重新显示任务。
q关闭本次连接保持关闭，重新打开会话时可恢复。
