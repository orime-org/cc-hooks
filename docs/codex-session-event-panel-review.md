第一轮提出的修订顺序为：活动 hook 优先查已有会话的存活进程登记；首次会话从同 cwd 的实际交互 Codex 进程中选择最新未关联实例，同进程切换会话时沿用自动选择规则；保存会话与 PID 的关联；WezTerm 在准备绑定时消费该 PID 的活动会话记录。Python 依赖继续使用标准库；系统进程信息的 macOS 实测接口为 ps 与 lsof，Linux 的对应系统接口由第 4 节记录修订结果。

多个同目录实例同时首次提交时仍使用启发式自动关联。该限制与原设计一致。
